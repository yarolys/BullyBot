# BullyBot

Telegram-бот для администрирования фан-сообщества TikTok-аккаунта **TolkoKit**.

Учебный проект, доведённый до рабочего состояния и деплоя: aiogram 3, PostgreSQL, Celery + Redis, Docker Compose, CI/CD через GitHub Actions.

> **Статус:** проект завершён, активно не развивается. Оставлен как пример архитектуры Telegram-бота с фоновыми задачами и панелью администратора.

---

## Возможности

**Приветствие новых участников**
Настраиваемое сообщение при входе в группу — текст редактируется прямо из админ-панели, без правки кода и передеплоя.

**Кнопки со звуками**
Библиотека звуковых фрагментов, которые участники отправляют в чат. Набор пополняется через админ-панель.

**Кнопки-ссылки**
Быстрые переходы на внешние ресурсы сообщества, тоже редактируются администратором.

**Расшифровка голосовых сообщений**
Пересланное голосовое превращается в текст через Google Speech Recognition. Обработка вынесена в Celery, чтобы не блокировать бота на время распознавания.

**Панель администратора**
Отдельный интерфейс со сценариями на FSM: управление приветствием, звуками, кнопками и пользователями.

## Стек

| Слой | Технологии |
|---|---|
| Бот | aiogram 3.15 (FSM, роутеры, фильтры) |
| Хранилище | PostgreSQL, SQLAlchemy, Alembic |
| Фоновые задачи | Celery 5.4, Redis |
| Распознавание речи | SpeechRecognition (Google API) |
| Инфраструктура | Docker Compose, supervisord |
| CI/CD | GitHub Actions |

---

## Структура

```
src/
├── handlers/            обработчики команд и колбэков
│   ├── panel_for_admin/   админ-панель: звуки, кнопки, приветствие
│   ├── panel_for_user/    пользовательский интерфейс
│   └── join2group.py      приветствие новых участников
├── database/
│   ├── models/            User, Sound, Buttons, Settings
│   └── migrations/        Alembic
├── utils/
│   ├── keyboard/          клавиатуры
│   ├── welcome_message.py
│   └── filter.py          кастомные фильтры доступа
├── states/                FSM-состояния админ-сценариев
└── config.py              настройки из окружения
```

## Запуск

```bash
git clone https://github.com/yarolys/BullyBot.git
cd BullyBot
cp .env.example .env      # заполнить токен и доступы к БД
docker compose up -d
```

Миграции:

```bash
alembic upgrade head
```

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `BOT_ADMIN_ID` | Telegram ID администратора — доступ к панели управления |
| `SQLALCHEMY_URL` | строка подключения к PostgreSQL |
| `LOG_LEVEL` | уровень логирования, по умолчанию `INFO` |

## Чему научил проект

- Асинхронная архитектура на aiogram 3: роутеры, FSM, кастомные фильтры
- Вынос долгих операций (распознавание речи) в Celery, чтобы бот оставался отзывчивым
- Миграции схемы через Alembic вместо ручных правок
- Контейнеризация и автодеплой — от `docker compose` до GitHub Actions
- Конфигурация через переменные окружения, секреты вне репозитория
